## 内容维度（每个朝代都要有）

### 1. 朝代概览（已有）
- 都城、开国、末代、起止年
- 极盛人口、极盛疆域
- 极盛年份（用于疆域图选点）

### 2. 一句话定位
> 例：秦 = "中国第一个大一统中央集权王朝"
> 例：宋 = "文治盛极而武备稍逊的朝代"

### 3. 朝代因何而兴（3-5 条）
> 例：秦 = ①商鞅变法 ②七代积累 ③六国内斗 ④人才汇聚 ⑤地理优势
> 例：明 = ①元末农民战争 ②红巾军 ③朱元璋崛起 ④"驱逐胡虏"号召

### 4. 朝代因何而亡（3-5 条）
> 例：秦 = ①暴政 ②滥用民力（长城/陵墓）③严刑峻法 ④秦二世昏庸 ⑤六国遗民反抗
> 例：唐 = ①安史之乱后藩镇割据 ②黄巢起义 ③宦官专权 ④朋党之争 ⑤朱温篡唐

### 5. 帝王长廊（3-5 位主要皇帝）
```
[
  { name: "汉武帝", reign: "前 141 - 前 87", 56年, achievement: "..." },
  { name: "光武帝", reign: "25 - 57", 32年, achievement: "..." }
]
```

### 6. 大事年表（8-10 个事件，按时间排序）
```
[
  { year: -221, title: "统一六国", desc: "韩赵魏楚燕齐尽灭" },
  { year: -215, title: "北击匈奴", desc: "蒙恬收河南地，筑长城" }
]
```

### 7. 经济数据
- 人口峰值（万）
- 垦田面积（万顷）
- 铸币量
- 税收（万石/万贯）
- 重要商路

### 8. 军事事件
- 关键战役（5-8 个）
- 著名将领
- 军事制度（府兵制 / 募兵制 / 八旗等）

### 9. 文化遗产（3-5 大类）
- 文学
- 艺术
- 科技发明
- 重大工程
- 思想哲学

### 10. 对外关系
- 北方（匈奴/突厥/蒙古/沙俄）
- 西方（西域/中亚/波斯）
- 南方（南洋/日本/朝鲜）
- 外交事件（和亲/册封/战争）

### 11. 疆域变化（节点 + 简要）
- 起：基本盘
- 中期：扩张里程碑
- 末期：收缩节点

### 12. 史家评价（引用 1-2 句经典评价）
> 例：清 = "康乾盛世实为回光返照，盛世之下危机四伏"（史学界共识）

## UI 改造方向

详情面板从"单列堆字段" → **多 Tab 分维度**：

```
[概览 | 帝王 | 大事 | 文化 | 疆域]
  ↓
每个 Tab 内部：
  概览 Tab：图 + 简介 + 因何而兴 + 因何而亡
  帝王 Tab：帝王长廊卡片网格
  大事 Tab：D3 子时间线 + 事件列表
  文化 Tab：分类卡片（文学/艺术/科技/工程）
  疆域 Tab：动态疆域形变（slider 拖时间）
```
