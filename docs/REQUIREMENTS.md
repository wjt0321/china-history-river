## 一、项目定位

**一句话定义**：一件以"中国历代疆域动态变化"为主线的交互式数据可视化网页作品，用于个人作品集。

**目标用户**：作品集评审（前端工程师 / 设计岗面试官 / 设计同行）。

**核心价值**：
- 用现代前端技术栈讲述 5000 年历史
- 视觉上达到"博物馆级"科技感 + 古风呼吸
- 技术上体现 D3 / Mapbox / WebGL 后期三件套的硬实力

## 二、视觉风格

### 2.1 主色调（v2 博物馆级）
- **背景**：深空黑（#0A0E1A ~ #050810）+ `CartoDB dark_nolabels` 暗色地形底图
- **主色**：降饱和文物色系（古铜锈、沉朱砂、褪金、墨绿、土褐）
- **强调色**：低饱和朱砂（#8B3535）
- **辅色**：玄墨（#1A1F2E）、宣纸黄（#C8B896，仅作微点缀）
- **朝代色规则**：每个朝代颜色需模拟"博物馆昏暗灯光下的出土文物"观感

### 2.2 风格关键词
- **数字博物馆** — 古画卷轴、展柜陈列、历史厚重
- **有机形态** — 河流时间轴、花瓣/萤火/落雪粒子
- **低饱和质感** — 拒绝数字荧光色，追求氧化/风化/褪色效果

### 2.3 反例（明确不要）
- 扁平卡通 / 鲜艳糖果色 / 高饱和荧光
- 过度水墨（喧宾夺主）
- 纯科技感 / 纯极简（缺人文温度）
- 进度条式时间轴（像Loading条）

## 三、内容范围

### 3.1 朝代粒度
**12 个主朝代**（不含分裂期细分）：
1. 夏（约前 2070 - 前 1600）
2. 商（约前 1600 - 前 1046）
3. 周（西周 + 东周 / 春秋战国，前 1046 - 前 256）
4. 秦（前 221 - 前 207）
5. 汉（西汉 + 东汉，前 202 - 220）
6. 三国（220 - 280）
7. 晋 + 南北朝（266 - 589）
8. 隋（581 - 618）
9. 唐（618 - 907）
10. 五代十国（907 - 979）
11. 宋（北宋 + 南宋，960 - 1279）
12. 元（1271 - 1368）
13. 明（1368 - 1644）
14. 清（1636 - 1912）

> 注：实际展示为 12-14 个分组，按"叙事流畅度"再调整。

### 3.2 信息架构（四级下钻）
```
朝代（地图高亮 + 摘要）
 └─ 皇帝/时期（右侧时间线展开）
     └─ 重大事件（地图上闪烁 + 弹窗）
         └─ 数据卡片（人口 / 疆域面积 / 文化指标）
```

### 3.3 数据维度（每朝代需具备）
- 起止年份
- 都城
- 开国君主 + 末代君主
- 鼎盛时期疆域面积
- 3-5 个标志性事件
- 文化/科技成就 1-2 项（造纸术、印刷术、京杭大运河等）
- 人口峰值

## 四、交互设计

### 4.1 主交互
- **河流时间轴**：底部 Canvas 河流，河段即朝代；点击河段切换选中朝代
- **地图交互**：底图固定缩放，疆域 GeoJSON 动态填充；都城标记同步切换
- **右侧详情面板**：卷轴式设计，展示朝代简介 + 场景图 + 人物图
- **二次下钻**：后续阶段补充皇帝/事件/数据卡

### 4.2 动效原则
- **疆域切换**：颜色溶解过渡（MapLibre `transition: {duration:900}`），非突变
- **时间轴**：当前朝代脉冲高亮，河段颜色渐变过渡
- **粒子切换**：朝代改变时粒子主题 1.5s 淡入淡出
- **面板切换**：Framer Motion 滑入 + 透明度渐变

### 4.3 细节效果
- 全屏氛围粒子（萤火/尘埃/花瓣/落雪）
- 卷轴面板木质轴头 + 内阴影
- 都城标记圆点+标签

## 五、技术栈

| 层 | 选型 | 备注 |
|---|---|---|
| 构建 | Vite + React 18 + TypeScript | 现代标配 |
| 地图 | MapLibre GL | 开源 fork，无需 token，支持 GeoJSON |
| 底图瓦片 | CartoDB dark_nolabels | 栅格瓦片，`opacity:0.55` 弱化 |
| 疆域数据 | GeoJSON | 按朝代分文件，颜色通过 `paint` 动态切换 |
| 时间轴 | **Canvas 2D 手绘** | 河流式：正弦中心线 + 渐变填充 + 脉冲高亮 |
| 粒子系统 | Canvas 2D | 全屏氛围层，4种主题按朝代切换 |
| 动效 | Framer Motion | 详情面板入场/切换 |
| 状态 | Zustand | 轻量全局状态 |
| 部署 | Vercel | 作品集直链 |

### 5.1 关键技术难点
1. **Mapbox + WebGL 后期叠加**：Mapbox 内部就是 WebGL，需要在它的 canvas 之上再叠一层 quad 做后期。
2. **疆域形变**：不同朝代的 TopoJSON 几何不一致，需要 shared topology 或形变插值。
3. **D3 + React 整合**：D3 操作 DOM，React 也要操作 DOM，需要明确边界（计算用 D3，渲染用 React）。

## 六、数据来源（合规清单）

### 6.1 疆域数据
- **CHGIS（China Historical GIS）**：哈佛大学公开学术数据集
  - 网址：https://sites.fas.harvard.edu/~chgis/
  - 协议：CC BY-NC-SA 4.0（需保留署名 + 非商业）
  - 用途：朝代疆域多边形
- **谭其骧《中国历史地图集》**：作为交叉验证（公开出版物）

### 6.2 朝代信息
- **维基百科中文版**：CC BY-SA 4.0（需署名 + 共享）
- **中华文明大辞典 / 国学网**：交叉验证

### 6.3 数据使用原则
- 所有数据在 `data/` 目录下，附带 `SOURCES.md` 说明出处
- 部署页底部固定显示数据来源与协议
- 不使用任何受版权保护的图片 / 视频
