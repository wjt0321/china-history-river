# 阶段 3 视觉 overhaul 设计案：史诗长卷

> 日期：2026-06-12
> 设计方向：A（故宫数字文物展）+ C（水墨长卷）
> 状态：设计稿，待评审，未进入实现

---

## 1. 设计愿景

把当前"深色数据看板"升级成**可交互的数字长卷**：

- **第一眼**像展开一幅故宫典藏的水墨舆图；
- **切换朝代**像翻过一卷史册，有印章落下、墨色晕染、山河变色的仪式感；
- **整体气质**庄重但不压抑，留白但不空洞，让用户感到"站在时间长河之上俯瞰中华"。

关键词：**宫墙朱、石青、金箔、宣纸、水墨、印章、长卷、俯瞰**。

---

## 2. 核心设计原则

| 原则 | 说明 | 反例（当前要避免） |
|---|---|---|
| **博物馆展陈感** | 每个朝代都像玻璃展柜里的文物，有灯光、标签、底托 | 纯扁平信息卡片 |
| **水墨流动感** | 过渡用晕染、飞白、拖尾，而不是机械淡入淡出 | 简单的 opacity 切换 |
| **恢宏尺度感** | 地图占满视觉中心，UI 像悬浮在画卷上的题跋 | 地图被边框和面板挤压 |
| **克制的高级感** | 颜色降饱和、动画慢而稳、音效可有可无 | 高饱和、闪动、快节奏 |

---

## 3. 整体视觉体系

### 3.1 色彩

以"宫墙夜色 + 宣纸微光"为底：

- **背景**：`#0c0b09`（墨黑）+ 极淡米黄 `#f5f0e6` 噪点纹理，模拟旧绢在暗室中的质感。
- **主色**：
  - 宫墙朱（降饱和）：`#8B3535` / `#9c4a4a`
  - 石青（降饱和）：`#2a5a6a`
  - 金箔（暗金）：`#B8943A`
  - 墨色层次：`#1a1a18` → `#3a3a36` → `#6a6a60`
- **朝代色**：保留现有文物色系，但全部叠加 5%-10% 宣纸纹理，降低塑料感。

### 3.2 字体

- **朝代名 / 大标题**：书法体或厚重宋体，如：
  - 思源宋体 Heavy（Source Han Serif，开源，无需授权）
  - 站酷庆科黄油体 / 方正清刻本悦宋（如可商用）
- **年号 / 数字**：小型大写或等宽旧体数字，避免现代科技感。
- **正文**：思源宋体 Regular，行高 1.8，营造古籍排版感。
- **标签 / 角标**：细宋体或楷体，字号小、字间距略宽。

### 3.3 纹理

全局叠加三层极淡纹理（opacity 0.03-0.08）：

1. **宣纸纤维噪点**：固定全屏，不随滚动移动。
2. **暗角 vignette**：四角压暗，聚焦中心地图。
3. **边缘磨损**：模拟古卷边缘轻微破损和泛黄（仅顶部/底部少量）。

---

## 4. 地图视觉 overhaul

### 4.1 底图

- 放弃 CartoDB dark_nolabels 栅格底图。
- 改用**自定义矢量/纯色底图**：
  - 海洋/背景：接近 `#0c0b09`，与页面背景融为一体。
  - 陆地轮廓：淡墨线 `#3a3a36`，线宽 0.5，带轻微 blur。
  - 主要山脉/河流：用更淡的墨线勾勒，不抢朝代疆域的戏。
  - 无现代城市、道路、国界线标签。
- 可选：保留 CartoDB 但重度调色（saturation -1, opacity 0.25），作为低成本 fallback。

### 4.2 朝代疆域

- **填充**：从纯色块改为"水墨晕染"效果。
  - 核心区域：朝代色 opacity 0.5-0.6。
  - 边缘：向外淡出成半透明墨晕，用 radial gradient 或 canvas 后处理模拟。
  - 内部：叠加极淡的宣纸纹理，避免塑料感。
- **边界**：
  - 外层：粗墨线 + blur，模拟毛笔飞白边缘。
  - 内层：锐利细线，勾勒实际疆域。
- **切换动画**：
  - 旧疆域像墨被水冲开一样淡去（800-1200ms）。
  - 新疆域从中心点像墨滴在宣纸上晕开一样扩展（900-1500ms）。
  - 可选：切换时短暂出现"山川河流"水墨笔触划过屏幕。

### 4.3 都城与事件标记

- **都城**：改为"朱印"样式——红色圆印 + 篆体/楷体都名，hover 时印泥微亮。
- **事件标记**：
  - 核心：金色/朱色小圆点。
  - 外圈：水墨晕染扩散动画（像一滴墨落在纸上）。
  - 连线：事件与都城之间可拉一条淡墨虚线（可选，避免杂乱）。
- **Popup**：做成"题跋"样式——竖排或横排小字，背景是泛黄纸片，带印章角标。

## 5. UI 组件改造

### 5.1 顶部导航栏

- 从现代 glass-panel 改为**宫墙檐角 + 题跋**风格：
  - 左侧：项目名用竖排或横排书法字，旁边盖一枚小印章。
  - 中间：朝代下拉选择做成"玺印切换"——当前朝代名像印文，点击后展开一卷小简牍。
  - 右侧："查看详情"按钮改为"卷轴展开"图标或篆书"详"字。

### 5.2 时间轴（底部河流）

- 从正弦曲线河段改为**水墨长卷底部的河带**：
  - 底色：由左至右从淡墨渐变到浓墨，象征时间由古至今。
  - 朝代节点：用印章/玉玺形式表示，当前朝代印章高亮并微微下沉（像钤印）。
  - hover：节点旁浮现小楷年号与起止年。
  - 切换：点击后，河流像被拉动一样，当前节点滑到中央，带轻微水波涟漪。

### 5.3 详情面板

- 从右侧 glass-panel 改为**从右侧展开的卷轴**：
  - 上下有木质/玉质轴头，卷轴展开时轴头先固定，中间纸面展开。
  - 纸面背景：泛黄宣纸纹理，四角有淡淡的水渍。
  - Tab 标签：改为竖排或横排的"概览 / 帝王 / 大事 / 文化 / 疆域"，像卷轴上的分栏题签。
  - 内容区：
    - 标题用书法体 + 印章。
    - 引言/简介用宋体，首字下沉或带引首章。
    - 帝王卡片像"牌位"或"画像"，hover 时有展柜灯光效果。
    - 事件列表像"竹简"或"年谱"，年份用朱色小印标出。

### 5.4 氛围粒子

按朝代主题重新设计，不再是通用粒子：

| 朝代 | 粒子主题 | 视觉 |
|---|---|---|
| 夏商周 | 萤火/星斗 | 暗金、青绿小光点，缓慢上升 |
| 秦汉 | 尘埃/黄沙 | 土黄、赭石微粒，水平飘动 |
| 魏晋南北朝 | 落花/柳絮 | 淡粉、白，旋转飘落 |
| 隋唐 | 金粉/花瓣 | 金色、淡红，华丽但克制 |
| 宋元 | 雪/墨点 | 灰白、淡墨，斜向飘落 |
| 明清 | 落雪/灰烬 | 冷白、淡灰，缓慢下沉 |

粒子可带轻微拖尾，增强水墨流动感。

## 6. 动效与叙事节奏

### 6.1 入场仪式（Opening Sequence）

用户首次进入时，播放 8-12 秒开场：

1. **混沌**：全屏墨黑，只有零星金粉/星斗闪烁。
2. **开卷**：一道淡金光从中间裂开，像画卷被缓缓展开。
3. **现山河**：水墨底图从中心晕开，陆地轮廓浮现。
4. **落首印**：第一个朝代（夏）的印章从上方落下，钤在时间长轴起点。
5. **定局**：疆域晕开，时间轴、详情面板徐徐出现。

开场可加一个"跳过"按钮，默认自动播放一次。

### 6.2 朝代切换仪式

每次切换朝代不是简单切数据，而是小型仪式：

1. **旧朝隐去**：当前疆域像被水冲淡，opacity 降低 + blur 增加。
2. **印落**：新朝代印章从上方落下，钤在时间轴上，发出轻微震动感。
3. **新朝晕开**：新疆域从中心向四周墨晕扩散。
4. **camera 飞行**：地图飞到新朝中心，速度比当前更慢、更稳。
5. **卷轴更新**：右侧面板像换了一卷新画轴，内容重新展开。

总时长控制在 1.5-2.5 秒，不能拖沓。

### 6.3 微交互

- hover 时间轴节点：印章微亮 + 年号浮现。
- hover 事件标记：墨圈扩散 + 题跋 popup 滑出。
- hover 帝王卡片：卡片微抬 + 底部出现淡金光线。
- 切换 Tab：像翻页，新内容从右向左滑入，带纸张摩擦感。

---

## 7. 音效（可选 / 占位）

- 朝代切换：低沉的编钟/铜锣单音，尾音绵长。
- 印章落下：轻微的木石撞击声。
- hover 卷轴：极轻的宣纸摩擦声。
- 开场：古琴泛音 + 环境底噪。

**原则**：默认静音，提供开关；音效只起氛围作用，不能打扰。

## 8. 技术实现要点

### 8.1 可以复用的

- React + Vite + TypeScript 架构不变。
- MapLibre GL 继续负责地图核心。
- Zustand 状态管理不变。
- 现有朝代数据、GeoJSON、图片资源全部复用。

### 8.2 需要新增或重做的

| 模块 | 改动 |
|---|---|
| 地图底图 | 自定义 StyleSpecification 或 CartoDB 深度调色 |
| 疆域渲染 | Canvas 后处理 / MapLibre custom layer / 多层渐变填充 |
| 时间轴 | Canvas 2D 重绘为水墨河带 + 印章节点 |
| 详情面板 | Framer Motion 卷轴展开动画 + 新 CSS 纹理 |
| 顶栏 | 新布局 + 印章下拉 |
| 粒子系统 | 按朝代主题重写粒子形态和拖尾 |
| 开场动画 | 新增独立组件，首次访问触发 |
| 字体 | 引入思源宋体或书法字体，配置 font-display |

### 8.3 性能注意

- 水墨晕染效果如果用 Canvas 后处理，注意在低端设备上降级为简单 opacity。
- 全局纹理用 opacity 0.05 以下，避免噪点闪烁。
- 开场动画提供 `prefers-reduced-motion` 支持。

---

## 9. 建议实施顺序

为了避免一次改动过大，建议分 3 个小阶段：

1. **阶段 3.1 氛围基底**（1-2 天）：
   - 换背景色、加宣纸纹理、换字体、调暗角。
   - 顶栏和详情面板先做"卷轴化"。

2. **阶段 3.2 地图水墨化**（2-3 天）：
   - 自定义底图风格。
   - 疆域填充改成晕染效果。
   - 朝代切换动画改成墨晕扩散。

3. **阶段 3.3 叙事与细节**（2-3 天）：
   - 开场动画。
   - 时间轴印章化。
   - 粒子主题细化。
   - 音效占位与开关。

---

## 10. 成功标准

完成后，打开网页应达到：

- [ ] 不再像现代 dashboard，更像数字博物馆展品。
- [ ] 切换朝代时有明显的"翻卷"仪式感。
- [ ] 地图占据视觉主导，有俯瞰山河的尺度感。
- [ ] 颜色、字体、纹理统一在"宫墙夜色 + 水墨长卷"调性内。
- [ ] 动画流畅但不拖沓，60fps 在主流设备上稳定。
