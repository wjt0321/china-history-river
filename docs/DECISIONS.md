## 2026-06-11 视觉全面重做（第二轮迭代）

### D-009 视觉方向修正
- **问题**：首版配色过于饱和、底图纯色、时间轴像进度条，整体缺乏历史厚重感，用户反馈"像小学生做的Flash"。
- **决定**：从"深色科技感+古风点缀"转向**"数字博物馆 / 古画卷轴"**美学。
- **关键词**：文物质感、低饱和、宣纸底色、手绘地图、有机形态。

### D-010 颜色系统降级
- **决定**：全部14个朝代主色**降饱和**至类似出土文物的氧化色调。
- **示例**：夏 `#B87333` → `#8B6B4A`（古铜锈）、秦 `#D32F2F` → `#8B3535`（朱砂沉色）、唐 `#FFD700` → `#B8943A`（褪金）。
- **规则**：禁用纯黑/纯白/高饱和荧光色；所有颜色需通过"在博物馆昏暗灯光下看是否舒服"的测试。

### D-011 底图升级
- **决定**：放弃纯色背景，改用 `CartoDB dark_nolabels` 栅格瓦片作为底图。
- **参数**：`raster-opacity: 0.55`、`raster-saturation: -0.6`。
- **效果**：有真实地形/河流轮廓的暗色底图，既提供地理参照又不抢夺疆域高亮。

### D-012 疆域切换过渡
- **决定**：不再瞬间切换颜色，使用 MapLibre `paint` 属性 `transition`。
- **参数**：`duration: 900ms`。
- **效果**：朝代切换时疆域颜色缓慢溶解过渡，消除"闪一下"的廉价感。

### D-013 河流式时间轴（核心视觉锚点）
- **决定**：放弃D3 SVG轴，改为**Canvas手绘河流时间轴**。
- **设计**：
  - 中心线为正弦波动曲线，模拟自然河流。
  - 河宽 ∝ `peakArea`（疆域面积），大朝代河宽、小朝代河窄。
  - 河段间使用相邻朝代颜色渐变过渡。
  - 当前朝代有脉冲高亮发光。
  - 朝代名称/年份交替排布在河流上下两侧。
- **技术**：纯Canvas 2D，逐帧渲染，使用 `getState()` 读取当前选中态，避免React重渲染。

### D-014 卷轴式详情面板
- **决定**：右侧面板从"现代侧边栏"改为"古画卷轴"隐喻。
- **设计**：
  - 右边缘增加木质`scroll-roller`（渐变色+阴影模拟卷轴轴头）。
  - 面板背景使用深褐渐变（`#1a1410` → `#0f0a05`），去除现代边框。
  - 内容区域内部加细微内阴影，营造"展开卷轴"的纵深感。

### D-015 背景氛围粒子
- **决定**：全屏Canvas粒子层，按朝代切换粒子主题。
- **映射**：
  - 夏/商/周 → **萤火**（暖黄微光，暗示上古神秘感）
  - 秦/汉 → **尘埃**（灰黄微粒，暗示土木/长城/战争）
  - 三国/晋南北朝/隋/唐 → **花瓣**（淡粉飘落，暗示诗歌/文化盛世）
  - 五代/宋/元/明/清 → **落雪**（白点缓降，暗示北方/终结/肃穆）
- **技术**：固定定位Canvas，z-index:1，`pointer-events:none`；对象池管理60粒子；朝代切换时1.5秒淡入淡出。

### D-016 都城标记
- **决定**：在地图上为每个朝代标注都城位置。
- **实现**：MapLibre 的 `circle` + `symbol` 图层组合，圆点+标签同步切换。
- **数据**：14个都城坐标手工校准（如 长安 `[108.9, 34.3]`、北京 `[116.4, 39.9]`）。

### D-017 图片展示策略
- **决定**：场景图和人物图从 `background-size: cover` 改为 `object-fit: contain` + `max-height`。
- **原因**：避免人物被截头、古画被切边；保持画面完整性，四周留空反而更像"展柜陈列"。

### D-018 素材来源
- **决定**：所有场景/人物图片统一从 Wikimedia Commons 下载 Public Domain 素材。
- **代理**：下载脚本通过 `HTTP_PROXY=127.0.0.1:10808` 访问 Commons API。
- **新增**：本轮补充 夏/商/周/三国/五代 共5张场景图。

## 2026-06-12 阶段 2 — 血肉（内容深度）迭代

### D-019 事件地理坐标
- **决定**：为 `HistoricalEvent` 增加可选字段 `location`（地点名称）与 `coords`（WGS84 经纬度）。
- **规则**：仅对具有明确地理意义的事件补充坐标；无坐标事件仍保留在年表中，但不渲染地图标记。
- **范围**：14 个朝代各挑选 3-8 个关键事件补充坐标，覆盖都城、战役、改革、起义等。

### D-020 重大事件地图标注
- **决定**：在 MapLibre 上叠加事件标记图层，与疆域、都城标记共存。
- **实现**：
  - `event-markers` GeoJSON source + `event-dots`（核心圆点）+ `event-pulse`（脉冲外圈）circle layer。
  - 标记颜色复用当前朝代色，点击标记弹出 MapLibre Popup 显示年份、标题、地点、简介。
  - 朝代切换时自动清除旧标记并加载新朝代事件。

### D-021 事件列表与地图联动
- **决定**：详情面板「大事」Tab 与地图事件标记双向联动。
- **实现**：
  - Zustand 新增 `highlightedEventId` 状态。
  - hover/click 事件列表项时设置高亮 id，地图对应标记半径放大（`circle-radius` 数据驱动）。
  - 使用 `case` 表达式仅高亮当前 hover 的标记，避免全部标记一起变大。

### D-022 帝王长廊下钻
- **决定**：帝王卡片默认折叠，点击后展开显示完整功过详情。
- **实现**：本地 `useState` 管理当前展开项 + Framer Motion `AnimatePresence` 做高度/透明度动画。

### D-023 数据卡片增强
- **决定**：在「疆域」Tab 增加数据对比条，将疆域面积、人口与历史峰值做百分比可视化。
- **实现**：纯 CSS 百分比条，宽度 = 当前值 / 峰值最大值，颜色为当前朝代色。
- **峰值基准**：疆域 1400 万 km²、人口 45000 万（以清朝峰值作为 100% 参照）。

## 2026-06-13 阶段 3 — 视觉打磨与工程加固

### D-024 站点图标
- **决定**：使用朱印风格 SVG 作为 `favicon.svg`，强化“古画卷轴”品牌识别。
- **位置**：`public/favicon.svg`。

### D-025 工程加固
- **决定**：引入 Vitest + React Testing Library，建立 `__tests__` 目录。
- **范围**：
  - 工具函数测试（`color.test.ts`、`format.test.ts`）。
  - Store 测试（`appStore.test.ts`）。
  - 朝代数据完整性测试（`dynasties.test.ts`）。
  - ErrorBoundary 测试（`ErrorBoundary.test.tsx`）。
  - URL 同步 hook 测试（`useUrlStateSync.test.ts`）。
- **规则**：每次合并前必须 `npm run test` 全部通过。

### D-026 错误边界
- **决定**：新增 `ErrorBoundary` 组件，对 MapView 与详情面板分区容错。
- **效果**：地图加载失败时显示降级提示，不影响整体应用。

### D-027 URL 状态同步
- **决定**：支持 `?d=<id>` 深链分享，刷新后自动恢复朝代。
- **实现**：`useUrlStateSync` hook，监听 Zustand `selectedDynastyId` 与浏览器 `hash/search`。
- **规则**：非法 id 回退到默认朝代。

### D-028 工程清理
- **决定**：合并前删除以下内容：
  - 冗余 `public/dynasties/all.json`。
  - 旧版下载脚本 `public/images/dl2.mjs`、`dl3.mjs`、`scripts/downloads/dl-seal.mjs`、`dl-yu.mjs`。
  - 废弃 hooks `useCanvasAnimation.ts`、`useResizeObserver.ts`。
- **原因**：减少维护面，避免历史脚本在仓库中造成混淆。

- **决定**：将 `iteration/pre-launch-cleanup` 分支通过 fast-forward 合并到 `main`。
- **流程**：
  1. 当前分支提交所有变更。
  2. 切换 `main` 并拉取最新。
  3. `git merge` 合并特性分支。
  4. 更新 README、ITERATION.md、DECISIONS.md、AGENTS.md。
  5. `npm run type-check && npm run test && npm run lint && npm run build` 验证。
  6. `git push origin main`。
  7. 运行 `deploy-gh-pages.bat` 更新 GitHub Pages。
